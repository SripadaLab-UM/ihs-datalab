# Practice processed data

Synthetic files shaped like the lab's processed-data folder in Dropbox: cleaned
datasets made from the study database. Nothing here is real. Practice DataLab
uses this folder wherever the real DataLab uses Dropbox.

- fitbit/: daily steps (2024, 2025) and nightly sleep (2025), one row per
  participant-day.
- surveys/: PHQ-9 totals by wave.
- mood/2025/: daily mood, one file per participant.
- codebook/variables.csv: what the columns hold.
