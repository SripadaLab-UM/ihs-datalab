# Practice sample files

The practice profile can't attach files from your computer, so it offers
these synthetic samples instead. Every identifier here is made up
(`SYN25-…`), matching the synthetic practice database.

- `sleep_diary_sample.csv`: a week of made-up sleep diaries for 12
  synthetic 2025 interns.
- `analysis_plan_notes.md`: notes for a practice analysis.
- `r_helpers/`: a folder with a small R helper, to try attaching a folder.
