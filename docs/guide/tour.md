# The tour

The tour is switched off for now, while it's reworked: it doesn't start by
itself and Help doesn't offer it. These are its steps.

## Ask a question

Start a conversation with **New conversation**, or pick one of the suggested
questions. In the practice DataLab the data are made up, so ask anything.

## Watch the steps

As the agent works, each step appears as a line in plain words, such as
"Queried FITBITDAILYDATA (2025)". One live line says what it's doing now,
with Stop beside it. A blue note means it's waiting for you, for example to
approve a plan.

## Open a step

Press **+** on any step to see what the agent saw: a table's columns, the SQL
it ran and how many rows came back, or a lab guide. Once the answer is in,
the steps fold into **How this answer was made**.

## Read the answer, its trace and review

The answer sits under a dark rule. Below it, the trace says whether its
numbers were found in this turn's outputs; a match means a number appears
there, not that it's right. The rigor review, if on, is the agent checking
its own work: a second opinion, not proof.

## Find the outputs and export

Files the agent made are in **Outputs**, beside the chat, with the queries it
ran in **Queries** and a copy after every turn in **History**. Only you can
export them: **Export** in the conversation's header.
